== 0. THE STARTING POINT (the agent students already know) ==
In the previous lesson, students built this 7-line terminal agent (agent.py):

    import asyncio
    import os
    from claude_agent_sdk import query, ResultMessage

    os.environ["ENABLE_CLAUDEAI_MCP_SERVERS"] = "false"   # optional: hides the claude.ai connectors warning

    async def main():
        async for message in query(prompt="Hello world!"):
            if isinstance(message, ResultMessage):
                print(message.result)

    asyncio.run(main())

A prompt goes in, query() streams messages back, the loop ignores the intermediate messages, and the final ResultMessage.result is printed. The web app must keep this exact pattern recognizable inside ONE back-end file, and wrap it with an API and a modern GUI.

== 3. BACK-END (FastAPI) ==
agent_service.py
- Set os.environ["ENABLE_CLAUDEAI_MCP_SERVERS"] = "false" before any query() call.
- run_agent(prompt) -> dict: the Lesson 0 loop, almost unchanged. It returns result, num_turns, duration_ms, total_cost_usd and is_error from the ResultMessage.
- stream_agent(prompt) -> async generator: the same loop, but it yields every message as a JSON-serializable dict {type: <class name>, summary: <short human-readable text>, data: <safe subset of fields>}.
- Web security: unlike the terminal app, web users must NOT get the agent's built-in tools (Bash, file read/write/edit, web fetch, etc.). Configure ClaudeAgentOptions so that no built-in tools are available and max_turns is small (default 1, configurable). Inspect the installed claude-agent-sdk 0.2.179 package for the exact option names. Do not guess them. Explain this in a code comment.
- Optional settings in config.py: CLAUDE_MODEL (empty = SDK default model), AGENT_SYSTEM_PROMPT (empty = none), AGENT_MAX_TURNS (default 1), CORS_ORIGINS (default http://localhost:4200).

Endpoints (all under /api, OpenAPI docs at /docs, with tags and descriptions)
- GET  /api/health -> {status: "ok", api_key_configured: true/false}. Never return the key itself.
- POST /api/agent/query   body {prompt} -> {result, num_turns, duration_ms, total_cost_usd, is_error}
- POST /api/agent/stream  body {prompt} -> Server-Sent Events. Send one "message" event per SDK message, then a final "done" event. Send failures as an "error" event instead of dropping the connection. Use FastAPI's native SSE support if fastapi 0.162.2 provides it (check the installed package). Otherwise use StreamingResponse with media type "text/event-stream". Do not add extra SSE libraries.
- Validation: prompt is required, trimmed, 1 to 4000 characters. Return clean JSON errors. Never leak stack traces or the API key.

Windows note (must be handled): the SDK starts the Claude Code CLI as a subprocess, which needs the Proactor event loop on Windows. Running uvicorn with --reload on Windows can raise NotImplementedError. Create backend/run.py that starts uvicorn in a way that works on Windows, macOS and Linux, test it on this machine, and explain the issue in the README.
