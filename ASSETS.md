# Visual reference and assets

The course presentation draws on [Udemy-Claude-Agent-SDK-lesson01-app](https://github.com/luiscoco/Udemy-Claude-Agent-SDK-lesson01-app), supplied by the user as the design reference. Its large text, blue and orange accents, rounded cards, numbered explanations and five lesson sections informed this application.

`frontend/public/astronaut.png` was downloaded unchanged from [public/astronaut.png at commit 832439954c11d4f3623d1b4a311f7dd67389fcc8](https://github.com/luiscoco/Udemy-Claude-Agent-SDK-lesson01-app/blob/832439954c11d4f3623d1b4a311f7dd67389fcc8/public/astronaut.png). It is included locally for this user-requested adaptation.

This app retains its own Python SDK backend, disabled tools, Hello world prompt and Angular client. The reference's TypeScript file-discovery exercise is not part of this application.
